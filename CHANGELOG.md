## Unreleased — documentation and reproducibility metadata

The following documentation package is prepared as a prospective additive update:

- Added the MIT License for the SEMKR source code and repository documentation; third-party datasets and external resources remain outside this licence.

- Added data-format and reproducibility notes under `docs/`.
